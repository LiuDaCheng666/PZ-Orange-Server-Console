# PZ 服务端流式稳定性补丁

已验证兼容 Project Zomboid `v42.20.2` 与 `v42.20.3`。

这是独立的服务端 Java Agent，当前只实现第一阶段的 `ObjectModData` 防护。它尚未部署到正式服，也没有加入任何启动脚本。

## 当前实际行为

- 对 `objectId=-1` 等无法识别目标的数据完整消费并丢弃，不再逐条刷两条警告。
- 仅当对象索引有效且目标方格尚未加载时，进入最多 5 秒的有界等待队列。
- 相同连接、坐标、对象类型和对象索引采用最后写入覆盖。
- 方格加载后在 `ServerMap.preupdate()` 主线程重放，保持世界对象修改的线程约束。
- 方格已经加载但索引无效时直接丢弃，不猜测或替换目标对象。
- 队列默认最多 2048 条、每连接 128 条、总负载 16 MiB、每 Tick 最多使用 1 ms。

## 尚未实现并强制关闭

- 压缩区块内存缓存
- Cell 接入时间预算
- 玩家方向预取

## 安全边界

- 只支持当前 `projectzomboid.jar` 中白名单 SHA-256 的两个类。
- 类哈希或方法结构不匹配时保留原版类，不尝试模糊修改。
- 不改变存档格式，不持久化等待队列。
- 移除 `-javaagent` 参数并重启即可回退。
