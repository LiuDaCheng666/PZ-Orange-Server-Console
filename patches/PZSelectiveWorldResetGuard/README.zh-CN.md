# PZSelectiveWorldResetGuard

这是选择性地图重置工具的服务端运行时防护，不能脱离工具生成的清单单独完成地图重置。

## 作用

- 服务器启动时读取存档根目录的 `orange-selective-reset-guard-v1.txt`。
- 将清单中的重置区块加入原版 `VehiclesDB2` 已生成集合，阻止原版停车车辆和随机车祸重新生成。
- 不删除或修改 `vehicles.db`，已有车辆、后备箱、附件和 Mod 主动创建车辆不受影响。
- 重置区块首次加载完成后，使用原版 `IsoRegionWorker` 重建已失效的墙体、地板、屋顶和室内区域缓存。
- 缓存文件已经重新生成且时间不早于本次重置时，不再重复排队。

## 加载

```text
-javaagent:server-patches/PZSelectiveWorldResetGuard-agent.jar
```

Agent 没有参数。没有重置清单时只输出一次状态，不改变原版车辆和区域行为。游戏类哈希不符时拒绝注入。

## 存档与回滚

防护清单位于存档内部。地图重置前的完整 ZIP 不包含新清单；执行完整回滚后，地图、区域缓存和清单会一起恢复到重置前状态。

清单中的 `V` 记录需要长期保留，因为 B42 的 `vehicles.db` 没有单独持久化“空区块已经生成过车辆”的记录。不要在服务器运行时手工编辑清单。
